# VisiaEngine 白皮书

### 多维空间可视化引擎

**版本 0.1.0 | 2026 年 9 月**

---

## 摘要

**VisiaEngine（维视引擎）** 是一个开源的、轻量级的多维空间可视化引擎。它提供统一的 **2D、2.5D 与 3D 渲染管线**，专为处理**地图、地理信息（GIS）、三维模型、仿真场景及数字孪生数据**而设计。

VisiaEngine 不追求游戏级的光影特效，而是专注于**清晰、精准、高效地展示数据**。它以高性能的 **Rust** 语言实现核心，采用灵活的 **SDK 形态**，可嵌入到 **Qt、Flutter、C# 及 Web** 应用中，并计划推出官方编辑器 **Visia Studio**。本项目采用 **Open Core** 模式，核心运行时永久开源，高级企业功能与编辑器作为商业产品。

## 1. 问题与机遇

### 1.1 现状的撕裂
当前的可视化工具市场存在显著的断层：
- **游戏引擎（Unreal, Unity）**：体积庞大、GIS 支持薄弱、难以嵌入普通桌面/Web 应用，且"游戏风格"的渲染往往过度分散数据可视化的注意力。
- **GIS 与 Web 三维库（Cesium, MapLibre, deck.gl）**：虽擅长地理数据展示，但大多受限于 Web 栈，深嵌原生桌面框架（Qt、WPF）代价高；即使提供 2D/2.5D/3D 模式切换的成熟产品，跨维度也往往各用一套场景语义，难以做到同一场景树、同一图层/实体语义的无缝过渡。
- **通用图形框架（Three.js, Qt 3D）**：缺乏为空间数据专门优化的图层、坐标转换与交互系统，开发门槛高。

### 1.2 未被满足的需求
开发者迫切需要一种**介于轻量库与重型引擎之间的解决方案**：
- 原生支持 **2D 地图、2.5D 倾斜视角与 3D 场景** 的同一视口平滑过渡。
- 对 **GIS 坐标系、矢量瓦片、ODR 高精道路** 等空间数据有原生的理解与优化。
- 既可打包为轻量 SDK 嵌入现有应用，又能作为独立引擎驱动未来的编辑器。
- 性能卓越，跨平台一致，且能为数字孪生和工业仿真提供可靠的可视化基底。

## 2. VisiaEngine 是什么

**VisiaEngine** 是一个以 **数据清晰呈现** 为首要目标的多维度可视化引擎。
- **Visia** 取自 vision 语族（拉丁语 visio，"视觉"），寓意 **"视觉之域"**。
- 它不是游戏引擎，不与 Unreal 或 Unity 竞争；它专注于**将复杂的空间数据转化为直观、可交互的视图**。

### 核心信条
> **Visia —— 看见数据的本质。**
> *Visia — See the essence of your data.*

## 3. 核心特性

### 3.1 统一的 2D / 2.5D / 3D 核心
- 同一场景树下，自由切换 **鸟瞰地图（2D）**、**倾斜视角（2.5D）** 与 **完全沉浸的 3D 视口**。
- 所有图层、实体、标注在多维度间保持一致的交互逻辑。

### 3.2 一流的空间数据能力
- **地图与 GIS**：内置对矢量瓦片、GeoJSON、WMS/WMTS 以及主流坐标投影的支持。
- **自动驾驶与仿真**：通过官方仿真插件支持 **OpenDRIVE (ODR)** 与 **OpenSCENARIO (OSC)**，自动生成道路和交通场景（Beta 提供，见路线图）。
- **模型与 BIM**：高效加载 glTF、点云等标准格式，支持建筑信息模型的高保真轻量化展示。

### 3.3 轻量、可嵌入、高性能
- **Rust 内核**：内存安全，无 GC，性能可媲美 C++。
- **基于 wgpu 的现代渲染**：一等支持 Vulkan / Metal / DX12 / WebGPU；同时提供 OpenGL 3.3+ / OpenGL ES 3.0+ / WebGL2 降级兼容档——跨平台一致的是 API 面与质量分级语义，降级档以特性子集换取覆盖度。
- **SDK 形态交付**：作为运行时库 (`visia-core`, `visia-render`) 通过 C API 提供给 Qt、Flutter、C# (WPF/Unity) 等宿主使用，不绑架应用主循环。

### 3.4 为开发者而生
- 紧凑且可裁剪的模块化设计，启动体积可控制在 **10 MB 以内**。
- 清晰、稳定的 API，配合详尽的文档与示例。
- 未来可通过官方脚本或扩展系统（考虑 WebAssembly）进行二次开发。

## 4. 技术架构

### 4.1 核心理念
采用 **"引擎内核 + 可插拔渲染后端 + 应用层绑定"** 的架构。

```
┌──────────────────────────────────────────┐
│               应用层 (宿主)               │
│          Qt / Flutter / C# / Web         │
└───────────────────┬──────────────────────┘
                    │ FFI (C API)
┌───────────────────▼──────────────────────┐
│           VisiaEngine 核心 (Rust)        │
│  ┌──────────────────────────────────┐    │
│  │   visia-core: 数据模型, 空间索引,  │    │
│  │   坐标系统, 场景图, 资源管理      │    │
│  └──────────────────────────────────┘    │
│  ┌──────────────────────────────────┐    │
│  │   visia-render: 统一渲染抽象层    │    │
│  │   (Trait 定义, 渲染指令生成)      │    │
│  └──────────────┬───────────────────┘    │
│                 │                        │
│  ┌──────────────▼───────────────────┐    │
│  │   visia-render-wgpu (默认后端)    │    │
│  │   基于 wgpu 的自研渲染管线         │    │
│  └──────────────────────────────────┘    │
│  ┌──────────────────────────────────┐    │
│  │   未来可选后端                    │    │
│  └──────────────────────────────────┘    │
└──────────────────────────────────────────┘
```

### 4.2 关键设计决策
- **为何 wgpu 直用、自研管线？**（2026-09 后端终审结论）wgpu 提供 Rust 原生、跨 Vulkan/Metal/DX12/WebGPU 的现代 GPU 抽象，并自带 GL/GLES 降级后端（Windows 可选 ANGLE 构建）——SDK 的主循环所有权、体积预算与兼容分级全部可由引擎自持。复用现成引擎渲染栈（Bevy）经调研评估后未采纳：其渲染层与自身 ECS/App 框架不可分离，且上游 API 稳定性节奏与 SDK 的长期兼容承诺不匹配。`visia-render` 抽象层保留：未来可选后端（如移动端专属或企业定制）仍经同一 C API 兼容纪律接入。
- **2D/2.5D/3D 如何统一？** 所有可视图元（点、线、面、体）均作为空间实体存在，相机系统负责处理从透视到正交、从鸟瞰到倾斜的无缝变换，不需切换渲染器。

## 5. 应用场景

1. **地图与地理信息系统 (GIS)**
   作为替代 Mapbox/Leaflet 的新一代高性能桌面端/移动端地图组件，支持无级缩放和海量矢量数据叠加。

2. **数字孪生与智慧城市**
   将实时 IoT 数据流绑定至 2.5D/3D 场景，驱动设备、建筑、交通态势的动态呈现。

3. **自动驾驶仿真 (AV / ADAS)**
   通过官方插件消费 OpenDRIVE/OpenSCENARIO 数据，生成逼真的 3D 道路环境，用于传感器仿真和规控算法验证。

4. **AGV/AMR 调度与监控**
   在工业 WPF/Qt 应用程序中嵌入全场景 2D/3D 监控视口，实时绘制车辆、路径、任务和热力图。

5. **工业设计与模型展示**
   为 CAD/BIM 数据提供轻量、可嵌入的 3D 查看器，支持剖切、测量和标注。

## 6. 商业策略与路线图

### 6.1 Open Core 模型
- **开源核心**：`visia-core` 与 `visia-render` 运行时库完全开源，采用 MIT OR Apache-2.0 双许可，**已发布版本许可不可撤销、核心不追溯闭源**，可被任意商业或非商业项目集成。
- **商业产品**：
    - **Visia Studio**：面向设计师和开发者的可视化编辑器，提供场景搭建、样式配置、数据源管理及一键部署功能。采用订阅制。
    - **企业级插件与支持**：提供开箱即用的企业级 GIS、数字孪生及仿真插件，以及 SLA 保障的技术支持服务。

### 6.2 路线图

- **阶段 1: MVP (当前)**
    - 核心 Rust 库（`visia-core`、`visia-render`、`visia-render-wgpu`）
    - 基本的 glTF、GeoJSON 加载
    - 2D 地图与 3D 视口的自由切换演示
    - Qt/Flutter/Web 嵌入示例

- **阶段 2: Alpha**
    - 完善的空间索引与坐标系统
    - 2.5D 建筑白模与倾斜视角
    - C API 的稳定化与多语言绑定生成

- **阶段 3: Beta**
    - Visia Studio 预览版发布
    - ODR/OSC 解析与可视化插件
    - 数字孪生数据绑定与实时更新机制

- **阶段 4: 1.0 正式版**
    - 完整的编辑器与运行时产品发布
    - 插件市场与开发者社区建立
    - 正式的商业授权与支持服务上线
