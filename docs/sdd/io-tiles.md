> Phase 0 scope: the Rust-native foundation layer (tile math / MVT decode / FileSource / LRU / local geometry mapping).
> HTTP sources and the C API plane = Phase 1 (the whitepaper carries the dated commitment 2026-Q4, the B4 rewording is on record).

## IO-10: MVT (Mapbox Vector Tile) decoding
`decode_tile(bytes) -> MvtTile`: a hand-written minimal protobuf wire reader (zero protobuf dependencies; D5 lock discipline). Four-level decode: layer -> feature -> keys/values -> geometry commands; error classes: `Truncated` (buffer truncated, includes empty input) / `UnsupportedVersion(v)` (spec v2.1 = version 2, v1 explicitly rejected) / `BadWire` (malformed wire record: varint>10B, unknown wire type) / `BadGeometry` (command word id∉{1,2,7}, count=0, coordinate overflow of i32). Geometry command state machine: MoveTo=1 / LineTo=2 / ClosePath=7, command word = (id&7)|(count<<3); parameters = zigzag **delta** (the cursor starts at 0, MoveTo is delta semantics too — spec wording); ClosePath implicitly loops back to the start point and **emits no coordinate word** (points count = explicit point count, the closed flag is independent). values seven-type mapping: str/float(->Double)/double/int/uint/sint(zigzag)/bool. tags = packed varint pairs (key_idx, value_idx); `tags(layer)` lazily parses into name -> value.

## IO-11: slippy tile math
`TileId::new(z,x,y)`: domain-validated construction — x/y ∈ [0,2^z), out of range = None (wrap is a caller policy; this layer never silently wraps). `TileId::bbox() -> (min_x,min_y,max_x,max_y)` (EPSG:3857 meters): z=0 = the whole world (± half-perimeter 20037508.34…); slippy y=0 = the northernmost row (3857 y grows northward, the bbox y mapping is inverted); **seamless-neighbor law**: the shared edge coordinates of adjacent tiles are bit-equal (guaranteed by the pure-function bbox construction, locked by the geometry_map/adjacency tests). `WORLD_EXTENT` constant = 2πR (R=6378137).

## IO-12: tile source abstraction + LRU
`TileSource::load(z,x,y) -> Result<Vec<u8>,SourceError>` (sync facade = Phase 0 decision [adjudication 2]: a pull-model engine with host-driven frames, a millisecond-class file source gains zero from threads; the trait = the seam for Phase 1 async HTTP, the scheduler touches nothing). `FileSource`: directory tree `{root}/{z}/{x}/{y}.mvt`; missing = NotFound with the path, IO errors with context. `HttpSource`: **typed stub** — every load returns `Unsupported` (no silent dead ends, the scheduler can probe the capability surface). `LruCache`: stdlib-only (HashMap + monotonic stamp), evicts the minimum stamp on overflow (LRU semantics); touch on get. ponytail note: the O(n) eviction scan is imperceptible at tile magnitudes (hundreds); swap in an order dictionary at ten-thousand scale.

## GEO-27: MVT feature -> local geometry mapping
`GeoTile::from_layers(id, layers)`: tile-local integer coordinates (extent units, y-down) -> the 3857-meter world system: scale = tile_size/extent, **y flip** (MVT y-down -> 3857 y-up: px_y=0 = the tile's north edge = max_y); `GeoTile.origin` = the bbox southwest corner [min_x,min_y,0] (f64, D7 anchor); type mapping POINT(1)->Point/MultiPoint, LINESTRING(2)->Line, POLYGON(3)->Poly (**Phase 0: rings = separate Polys, holes not distinguished** — winding order is unreliable across producers, ponytail note = upgrade slot). attrs seven-type -> String normalization (the style consumption surface). `GeoTile::shifted()`: D7 re-basing view (world − origin = small-value local, vertices never bake the world-scale numbers — same discipline as the geo crate's GeoKind::shifted). The E206 consumption chain = decode -> map -> tessellate, isomorphic (Poly fan / StrokeSeg / PointMark, three render paths).

## IO-13: viewport tile enumeration (TileSet::visible)
`TileSet::visible(bbox3857, z) -> Vec<TileId>`: **half-open coverage** semantics — a tile is selected as soon as its open-interval area intersects the bbox; a max edge landing exactly on a tile boundary = zero-area contact that does not pull in the next tile (boundary snap on both sides: f is treated as the integer when within a relative eps = |f|·1e-12 of it — the lesson that an absolute eps fails at 2^z-scale f64 ulp, measured 4e-14, is on record). Row-major (y outer, x inner) deterministic order. No wrap: x/y outside [0,2^z) are pruned directly (wrap = caller policy).

## IO-14: ensure idempotent loading + accounting
`TileSet::ensure(ids) -> EnsureStats{loaded,cached}`: only cache misses go through source.load; a second call with the same ids = all hits (loaded=0). Aborts on the first error (typed Source/Decode errors propagate). `decoded(id)` = through-cache decode (second-level decoded_cache; a hit does not re-decode).

## IO-15: HTTP tile source (native)
`HttpSource::new(root)`: URL template `{root}/{z}/{x}/{y}.mvt`; native = ureq(rustls) synchronous GET (adjudication a: small / synchronous / thread-joining-free posture); HTTP 4xx/5xx = SourceError::NotFound (with the code), transport error = Io. **wasm = typed stub** (fetch is host-driven; the target-gate fix for the getrandom/js feature conflict is on record). Tests = an in-process std::net TCP server serving fixture bytes (**CI with zero external network**, PIT-7 discipline; live-network test = `#[ignore]` explicit).

## IO-16: pump-style non-blocking loading (TileSet::begin/pump/state, N1.4)
`begin(ids) -> usize`: Unloaded/FailedTemporarily -> Loading (pure state transition, zero I/O; Done/Loading skipped, idempotent). `pump(budget) -> (done,failed)`: at most budget source.load calls per invocation (the I/O budget = the engine-side implementation of the frame-budget guard); per tile Ok -> Done (into the LRU) / Err -> FailedTemporarily (error recorded, **no abort** — forking from IO-14 ensure's abort-on-first-error, the semantics keep separate books). `state(id) -> TileState`: four states (Unloaded/Loading/Done/FailedTemporarily; cesium's 7 states pruned to 4 — the FailedTemporarily/Failed split is retained, waiting states are not modeled). Retry policy = caller (begin re-arms). HttpSource guardrails: 5s global timeout (a hung server does not hang the host); loopback exempt from env proxies (http_proxy 502 on 127.0.0.1, measured 2026-09-28).

## IO-18: Raster tile payload lane (R band)
TileSet decoded-cache widens `HashMap<TileId, MvtTile>` → `HashMap<TileId, TilePayload>` (`enum TilePayload { Mvt(MvtTile), Raster{rgba,width,height} }`) — the generic-vs-parallel TileSet fork was the flagged design trap; enum wins on blast radius (pump/LRU/evict machinery stays single-lane). `FileSource::raster(root)` = same discovery tree with `.png` suffix (one type, one trait — the scheduler is format-agnostic: bytes in, decode lane chosen by caller entry). `decoded_raster(id)` = decode-through-cache (image crate, PNG/JPEG → RGBA8); WRONG-LANE reads return None without poisoning the cache (`decoded()` on raster bytes = None, `decoded_raster()` on MVT bytes = None). Sharing the pump/LRU/EVICT lifecycle is structural (no separate accounting to drift).
