# IO-*: text loading plane (visiaengine-io-text) behavioral contract

> Fixture source of truth: `resources/data/DejaVuSans.ttf` (permissively-licensed data asset, license text placed alongside;
> not linked into the crate, consumed only by tests/demos). Color-gamut-agnostic (this plane does zero color handling — color lives in the caller's LabelMark).
> Coordinate output: `LabelQuad.top_left_px=(right, up)` relative to the baseline anchor (y-up positive; the render side's vs_label flips the screen order).

## IO-07: FontFace loading contract
`FontFace::from_bytes(bytes)`: empty = `FaceError::Empty`; non-TTF/parse failure = `FaceError::Parse` (**no default font** — the text pipeline exists only after a successful load; timing gate = consumed by the CAPI-21/22 plane). **No embedded font** (the full CJK form at ~15 MB is unacceptable = host injection, same data shape as load_gltf/load_pcl). `rasterize(ch, size_px)` passes through fontdue's `(Metrics, Vec<u8>)` (bitmap = w×h row-major **top-down**); the domain gate `size_px>0 ∧ finite` lives at the IO-08 entry. Dependency lock shape `default-features=false, features=["hashbrown"]` (disabling SIMD = the proven wasm trap [fontdue #25/#72]; keeping hashbrown = under no_std, std/hashbrown must pick one [docs feature-flags]).

## IO-08: GlyphCache R8 atlas (shelf packing)
key = `(char, (size_px·10).round())` (f32 is not used as a key; same glyph at different sizes = different slots, `top = ymin+height` varies with font size). `get`: a hit returns the same slot (deterministic); a miss → rasterize + pack + mark dirty; **zero-coverage glyphs (space class, w0h0) record advance without taking atlas space or marking dirty**. Packing = shelf cursor + **1px gutter** (linear sampling prevents neighbor-glyph bleed); atlas full → `get` internally **clears everything and re-bakes once, then retries** (fontdue determinism = transparent degradation, jitter but no crash; a single glyph larger than the whole atlas = final None, the caller skips that glyph). `take_dirty()` = the texture-reupload signal (cleared after take). Atlas edge constant `GLYPH_ATLAS_PX=512` (R8 256 KB, ~1024 slots at an average 64² glyph; capacity-limit changes = this one place). Domain gate `size_px≤0/non-finite` → None. **Degradation note [ponytail]**: full reclaim, not per-glyph LRU — per-glyph LRU waits until profiling proves re-bake pain, then swaps at the one `reset()` site.

## IO-09: LTR layout (advance accumulation + bearing)
`layout(text, face, cache, size_px) -> (Vec<LabelQuad>, pen)`: **per-`char` codepoint order** (combining marks are neither split nor grouped into grapheme clusters = the declared boundary of tier 1; CJK per-character is naturally correct, Latin accented combining sequences are a known rough edge). pen accumulates `advance_width` from 0; the quad's `top_left_px=[pen_before+xmin, ymin+height]` (the **up-positive** convention); zero coverage = occupies advance but emits no quad; **empty string / `size≤0` = (empty, 0)**. Disaster tolerance for odd glyphs: cache returns None (oversized odd shape) → pen adds the empirical width `size*0.5` and keeps laying out (**the whole string is never discarded**). Total width = pen including the trailing advance (isomorphic to MapLibre: the centering shift uses this width). Determinism lock: same cache, same input, twice = field-for-field equal (test prefix lock).
